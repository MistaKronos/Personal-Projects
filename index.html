Test Engineer — Visma Enterprise AS

Procurement & Logistics Module

Sole owner of the automated test suite for the Procurement & Logistics module. Responsible for running, maintaining, and expanding end-to-end black box test coverage across the full feature set — from purchase orders and goods receipt to logistics workflows. In practice the role went well beyond pure testing and involved significant ownership: if tests weren't passing, it was on me to find out why and fix it.

Carried substantial infrastructure responsibility alongside the testing work. When frontend or backend builds went offline, I would locate the relevant GitHub Actions YAML, trigger the build, track down the deployment in Octopus Deploy, and promote it to Atlantis — our acceptance test environment — so automated tests could resume. Also managed test environment data through manual database backups and restores, and used feature flags to enable or disable features mid-sprint without touching code.
