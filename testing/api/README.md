# API Testing Examples\n\nThis folder contains API test examples and patterns for backend testing using REST Client and Jest.\n\n## Test Examples\n\n### `exam-project-api.rest` (REST Client Format)\n\nUsable in VS Code with the REST Client extension:\n\n```http\n### Initialize Exam Project Database\nPOST http://localhost:3000/init\nContent-Type: application/json\n\n### Get All Products\nGET http://localhost:3000/api/products\n\n### Get Product by ID\nGET http://localhost:3000/api/products/1\n\n### Create New Product (Admin)\nPOST http://localhost:3000/api/products\nContent-Type: application/json\nAuthorization: Bearer {token}\n\n{\n  \"name\": \"Test Product\",\n  \"price\": 99.99,\n  \"category\": \"electronics\",\n  \"stock\": 50\n}\n\n### Update Product\nPUT http://localhost:3000/api/products/1\nContent-Type: application/json\nAuthorization: Bearer {token}\n\n{\n  \"name\": \"Updated Product\",\n  \"price\": 149.99,\n  \"stock\": 30\n}\n\n### Delete Product\nDELETE http://localhost:3000/api/products/1\nAuthorization: Bearer {token}\n\n### User Login\nPOST test('should retrieve all products', async () => {\n      const response = await request(app)\n        .get('/api/products');\n\n      expect(response.status).toBe(200);\n      expect(Array.isArray(response.body)).toBe(true);\n    });\n\n    test('should retrieve product by ID', async () => {\n      const response = await request(app)\n        .get('/api/products/1');\n\n expect(response.status).toBe(404);\n    });\n\n    test('should create product with valid data', async () => {\n      const response = await request(app)\n        .post('/api/products')\n expect(response.status).toBe(201);\n      expect(response.body).toHaveProperty('id');\n      expect(response.body.name).toBe('New Product');\n    });\n\n    test('should validate required fields', async () => {\n      const response = await request(app)\n        .post('/api/products')\n        .set('Authorization', `Bearer ${validToken}`)\n        .send({\n          // Missing required fields\n const response = await request(app)\n        .post('/api/orders')\n        .set('Authorization', `Bearer ${validToken}`)\n        .send({\n          items: [\n            { productId: 99999, quantity: operations (Create, Read, Update, Delete)\n- Business logic validation\n- Data calculations (totals, discounts)\n\n✅ **Security**\n- Authentication (login, token validation)\n- Authorization (role-based access)\n- Input validation\n\n✅ **Error Handling**\n- Invalid requests (400)\n- Unauthorized access (401, 403)\n- Not found errors (404)\n- Server errors (500)\n\n✅ **Data Integrity**\n- Required field validation\n- Data type validation\n- Constraint validation (unique emails, positive prices)\n\n✅ **Edge Cases**\n- Empty lists\n- Boundary values\n- Concurrent requests\n- Rate limiting\n\n## Tools Setup\n\n### VS Code REST Client\n\n```bash\n# Install extension\nREST Client by Huachao Mao (from VS Code Extensions)\n\n# Usage: Right-click on .rest file → Send Request\n```\n\n### Jest + Supertest\n\n```bash\nnpm install --save-dev jest supertest @types/jest @types/supertest ts-jest\n```\n\n### Configuration (`jest.config.js`)\n\n```javascript\nmodule.exports = {\n  preset: 'ts-jest',\n  testEnvironment: 'node',\n  roots: ['<rootDir>'],\n  testMatch: ['**/__tests__/**/*.test.ts'],\n  collectCoverageFrom: [\n    'src/**/*.ts',\n    '!src/**/*.d.ts',\n  ],\n};\n```\n\n## Run Tests\n\n```bash\n# Run all API tests\nnpm test\n\n# Run with coverage\nnpm test -- --coverage\n\n# Run specific test suite\nnpm test -- orders.test.ts\n\n# Watch mode\nnpm test -- --watch\n```\n\n## QA Best Practices\n\n- **Isolation**: Each test should be independent\n- **Cleanup**: Reset data between tests\n- **Clarity**: Descriptive test names\n- **Coverage**: Aim for >80% code coverage\n- **Documentation**: Comment complex test logic\n\n---\n\n**Note**: These are examples. Real API testing would require a running server and database.\n
