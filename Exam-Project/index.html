Exam Project

This project is built with Node.js and Express. It is not a static HTML page, so open the folder in your editor and run it locally.

How to run it

  1. Open the Exam Project folder in terminal.
  2. Run npm install if needed.
  3. Run npm start.
  4. Visit http://localhost:3000 in your browser.
