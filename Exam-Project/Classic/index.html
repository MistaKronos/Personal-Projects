Exam Project Full-Stack

E-Commerce Admin Panel

A full-stack admin application for managing an e-commerce platform. Built with Node.js and Express on the backend, Sequelize ORM for database access, EJS templating for server-side rendering, and JWT-based authentication. Features include complete product catalog management, user roles, order tracking, and a winter-themed UI.

Features

Product Management

Full CRUD with image URLs, brand and category linking, soft-delete, and search/filter by name, brand, and category.

User & Role System

User accounts with Admin and User roles. JWT-based authentication stored as an httpOnly cookie.

Order Tracking

View and manage customer orders with line-item breakdown and order status.

Brand & Category Management

Manage the product catalog taxonomy with full CRUD operations for brands and categories.

Shopping Cart API

Cart management with line items, quantity adjustment, and checkout flow.

Membership Tiers

Bronze, Silver, and Gold membership levels with configurable discount rates.

Tech Stack

Node.js Express.js Sequelize ORM MySQL EJS Templates JWT Auth Bootstrap 5 Railway

Architecture

Built with a layered architecture: Routes handle HTTP endpoints and delegate to Services which contain all business logic, keeping controllers thin. Sequelize Models map directly to MySQL database tables with associations (Products belong to Brands and Categories, Orders have OrderItems, Users have Roles and Memberships). Authentication uses JWT signed with a secret, stored as an httpOnly cookie and validated by middleware on all protected admin routes. The database is seeded on first run via a /init endpoint that fetches product data from an external API.
